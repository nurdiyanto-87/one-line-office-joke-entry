A one-line joke about office life for make.fun's "One-Line Office Joke:
24-Hour Sprint" bounty: the daily standup where everyone reports "no
blockers" while the standup itself is the only thing blocking anyone.

`main.py` (pure Python standard library) writes the joke to
`/output/entry.txt` — one line, 122 characters, valid UTF-8.

## Run it

```sh
python3 main.py
```
